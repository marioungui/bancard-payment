# Bancard Gateway para WooCommerce

![Bancard Gateway para WooCommerce](https://emedos.com.py/bancard-update/banner-772x250.jpg)

Aceptá pagos en tu comercio a través de tarjetas de crédito o débito y billetera Zimple.

# Novedades
En la versión 1.3 añadimos las siguientes características.
  - Compatibilidad con pagos catastrados añadida
  - Permite registrar a tus clientes sus tarjetas de forma segura.


### Instalación

- Descargar el archivo ZIP (previa autorización de M2 Design)
- Subir e instalar como plugin en el panel de plugins de WordPress
- Habilitar los respectivos métodos de pago en WooCommerce -> Ajustes -> Pagos
- Subir las llaves públicas y privadas del portal de comercios en cada método de pago

¡Listo! Eso es todo.

### Requerimientos

- WordPress 5+
- WooCommerce 4+
- PHP 7+
